# ISO/IEC 27701:2019 — controles de privacidade (PIMS)

A ISO/IEC 27701 estende a ISO 27001/27002 com um sistema de gestão de privacidade. Ela tem três partes que interessam à matriz:

- **Cláusula 6**: orientação adicional de privacidade sobre os controles da 27002 (por exemplo, classificação que reconhece dado pessoal, logs que registram acesso a dado pessoal, backup que respeita retenção). Não repita os controles da 27001 aqui: acrescente a coluna "com dado pessoal?" na tabela da 27001.
- **Cláusula 7**: controles para **controladores de dado pessoal** (na norma, "PII controllers").
- **Cláusula 8**: controles para **operadores** ("PII processors").

Use a cláusula 7 para os tratamentos em que o projeto decide finalidade e meios (dados dos próprios usuários, clientes e leads) e a cláusula 8 para os tratamentos feitos por instrução de outro controlador (num SaaS B2B, os dados dos clientes dos clientes). Muitos projetos são os dois ao mesmo tempo. A norma está em revisão; registre a edição usada (2019) na matriz.

Correspondência com a LGPD, para a evidência apontar o que já existe em `.lgpd/`.
